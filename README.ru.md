# Анализатор хранилищ (Storage Analyzer)

> 🇬🇧 English version: [README.md](README.md).

Настольное приложение с графическим интерфейсом для **анализа содержимого
хранилищ**: локальные диски, сетевые папки SMB (Synology, QNAP и др.) и
объектные хранилища **S3** (AWS и S3-совместимые — MinIO, Ceph, Wasabi,
Backblaze). Программа перечисляет файлы/объекты, наглядно показывает их
характеристики (формат, категория, размер, даты, автор/владелец), позволяет
фильтровать, строить дерево по папкам, искать дубликаты, применять правила
(перенос/удаление старых файлов), работать по расписанию и слать уведомления в
Telegram.

Написана на **Python + PySide6 (Qt)**. Кроссплатформенная: Windows, macOS, Linux.

## Возможности

- **Источники в одной программе**: локальные диски, SMB-папки, бакеты S3 —
  в боковой панели, как в Finder (избранное, диски, облако S3, недавние).
- **Нативный интерфейс macOS**: строка меню и горячие клавиши (⌘O, ⌘R, ⌘F…),
  единая панель инструментов, иконки SF Symbols и Finder, перетаскивание папок,
  Quick Look, «Показать в Finder», светлая и тёмная тема.
- **SMB с логином/паролем** (Windows и macOS): встроенное подключение к сетевому
  хранилищу (Windows — с буквой диска, macOS — в `/Volumes`, со Связкой ключей);
  пароль не сохраняется на диск.
- **Анализ содержимого**: имя, тип (файл/папка), формат, категория, автор/владелец,
  размер, даты создания и изменения.
- **Два вида результата**:
  - **Список** — плоская таблица с быстрой сортировкой по любому столбцу;
  - **Папки (дерево)** — иерархия как в Проводнике, **ленивая** (мгновенно
    открывается даже на сотнях тысяч объектов), с показом **суммарного размера
    папок**.
- **Фильтры** (скрыты за кнопкой «Фильтры»): имя, формат, категория, тип, автор,
  диапазон размера и даты. Клик по строке категории в сводке — быстрый фильтр.
- **Сводка**: число элементов, общий размер, разбивка по категориям.
- **Действия над объектами**:
  - файлы — открыть, открыть расположение, копировать путь;
  - S3 — скачать, удалить, переместить под префикс, открыть по ссылке
    (presigned URL), копировать ключ.
- **Правила** (условие → действие): отбор файлов по настраиваемым условиям
  (возраст, размер, формат, категория, имя/маска/regex, автор, мусорные, пустые)
  и действие с предпросмотром и подтверждением.
- **Поиск дубликатов** по выбираемым полям (имя, размер, автор, дата создания,
  **хэш содержимого**) с переносом дублей в отдельную папку.
- **База данных (SQLite)** со **инкрементным** повторным анализом (обновляются
  только изменённые файлы) и **сжатием** (VACUUM).
- **Запуск по расписанию** (Планировщик Windows / cron на Unix): фоновый
  инкрементный анализ и автоархивация по правилам.
- **Уведомления в Telegram** при превышении заданного размера папки/бакета.
- Высокая производительность на **100k+** объектов (сортировка/фильтр/дерево —
  доли секунды).

## Быстрый старт

Нужен **Python 3.10+**.

```bash
pip install -r requirements.txt
python app.py
```

На Windows можно запустить двойным кликом по `run.bat` или взять готовый
`dist/FolderAnalyzer.exe` (сборка без установки Python).

На **macOS** — готовое приложение `dist/FolderAnalyzer.app` или установочный образ
`dist/FolderAnalyzer-2.0.dmg` (перетащите приложение в «Программы»), см.
[сборку](#сборка-портативной-версии). Системный `/usr/bin/python3` на macOS —
3.9, для запуска из исходников поставьте Python 3.10+ (python.org, Homebrew или
`uv venv --python 3.12`).

`boto3` нужен для S3; `pywin32` ставится только на Windows (помечен маркером в
`requirements.txt`) и даёт чтение автора, SMB-подключение и расписание.

## Использование

### Окно программы
Слева — **боковая панель** (как в Finder): «Избранное» (домашняя папка, Рабочий
стол, Документы, Загрузки…), «Расположения» (диски, флешки, смонтированные
SMB-ресурсы, «Подключиться к серверу…»), «Облако S3» и «Недавние». Клик по
пункту сразу запускает анализ. Папку можно также **перетащить в окно**.
В центре — строка пути, параметры анализа, фильтры и результат; справа —
**сводка** (карточки итогов и категории с долями объёма). Вверху — панель
инструментов и поле **«Поиск по имени»** (фильтрует на лету).

### 1. Выбор источника и анализ
1. Выберите источник:
   - **Папка/диск** — в боковой панели, кнопкой «Открыть» (⌘O), перетаскиванием
     или вводом пути (`/Users/имя/Папка`, `/Volumes/share`; на Windows —
     `C:\Папка`, `\\server\share\folder`). Поле пути подсказывает папки.
   - **SMB с логином** — «SMB» (⌘K): адрес `smb://server/share[/папка]`
     (Windows: `\\server\share`), логин, пароль. На macOS ресурс монтируется в
     `/Volumes` через системный NetFS; если пароль не вводить, macOS спросит его
     сама и предложит сохранить в Связке ключей. Ввод `smb://…` в строку пути
     тоже открывает подключение.
   - **S3** — «S3» (⇧⌘K): endpoint (для AWS пусто), регион, Access/Secret Key,
     бакет, префикс; «Проверить» проверяет доступ, профиль сохраняется и
     появляется в боковой панели.
2. Отметьте при необходимости: «С подпапками», «Показывать папки», «Определять
   автора» (медленнее), «Инкрементно (база)». Параметры запоминаются.
3. Нажмите **«Анализировать»** (⌘R). Скан идёт в фоне с прогресс-баром;
   «Стоп» — ⌘. .

### 2. Просмотр результата
- **Список** (⌘1) — сортировка кликом по заголовку, мгновенная даже на 100k+;
  иконки файлов — как в Finder/Проводнике.
- **Дерево** (⌘2) — строится по запросу (мгновенно, лениво): ветки раскрываются
  по клику, у папок — суммарный размер. «Развернуть/Свернуть всё» (⌥⌘→ / ⌥⌘←).
- **Фильтры** (⌥⌘F) — формат, категория, тип, автор, размер, дата изменения;
  применяются сразу при вводе, «Сбросить» — ⌥⌘R. Точка на кнопке «Фильтры •»
  означает, что фильтр активен. Действует на оба вида.
- **Сводка** справа: клик по категории («Видео», «Архивы», …) фильтрует список
  (повторный клик или «Сбросить» — сброс).
- **Экспорт** показанных строк в CSV — ⌘E.
- Размер окна, ширина панелей и столбцов, параметры и недавние папки
  запоминаются между запусками.

### 3. Действия
- Двойной клик по файлу — открыть; правый клик — контекстное меню:
  открыть, **быстрый просмотр** (пробел, macOS), показать в Finder/Проводнике
  (⇧⌘F), копировать путь (⌘C, можно для нескольких строк), «Анализировать эту
  папку».
- В режиме S3 меню содержит: открыть по ссылке, скачать, переместить под префикс,
  удалить, копировать ключ (можно выделять несколько объектов).

### 4. Правила (условие → действие)
Кнопка **«Правила…»** (после анализа):
1. Добавьте условия (объединяются по «И»): возраст старше/младше N дней/месяцев/
   лет, размер, формат, категория, имя (содержит/маска/regex), автор, мусорные
   файлы (`Thumbs.db`, `~$*`, `*.tmp`…), пустые (0 байт).
2. Задайте действие: для файлов — «переместить в папку»; для S3 — «удалить» или
   «переместить под префикс».
3. «Найти совпадения» → предпросмотр (число, объём) → «Выполнить» с подтверждением.
   Можно выгрузить список в CSV.
4. **Автоархивация по расписанию**: сохраните правило и создайте задание — оно по
   графику без подтверждения применит правило.

### 5. Поиск дубликатов
Кнопка **«Дубликаты…»**: отметьте поля сравнения (имя, размер, автор, дата
создания, **хэш содержимого**) → «Найти дубликаты». Дубль — где совпали все
отмеченные поля. Хэш считается в фоне и только внутри групп-кандидатов. Действие
«Переместить дубли» оставляет в каждой группе один файл (самый старый), остальные
переносит в указанную папку/префикс.

### 6. Расписание и уведомления
- **«Расписание…»**: периодичность (каждый день / N часов / N минут), время,
  порог уведомления в Telegram, на Windows — «как служба (SYSTEM)». Управление
  заданиями: создать, запустить сейчас, удалить.
- **«Настройки…» → «Настроить Telegram…»**: токен бота (@BotFather) и chat id
  (@userinfobot), «Проверить» шлёт тест.

### 7. Настройки и обслуживание базы
**«Настройки…»**: папка базы данных, размер базы, список снимков,
**«Сжать базу (VACUUM)»**, удаление снимка.

## Как это устроено (логика)

**Единая модель данных.** И файловый сканер, и листинг S3 приводят содержимое к
единому типу `FileEntry` (имя, путь, родитель, признак папки, расширение,
категория, размер, даты, автор). Благодаря этому таблица, дерево, фильтры, сводка,
правила и дубликаты работают одинаково для любого источника.

**Анализ (фон).** Обход выполняется в отдельном потоке (`QThread`), поэтому
интерфейс не блокируется; прогресс и результат передаются через сигналы Qt в
главный поток. Файловый обход — итеративный `os.scandir` (на Windows размер/даты
берутся из результата scandir без лишних системных вызовов). Автор/владелец
читается **параллельно** (пул потоков) и только для новых/изменённых файлов.

**Категории** назначаются по расширению (Видео, Аудио, Изображения, Документы,
Архивы, Код, Исполняемые и т.д.); профессиональный видеоформат `.mxf` отнесён к
«Видео».

**Список** — модель `FileListModel`: фильтрация и сортировка выполняются прямо над
Python-списком (без `QSortFilterProxyModel`), поэтому сортировка 100k строк
занимает миллисекунды.

**Дерево** — `LazyFileTreeModel` с ленивой подгрузкой: индексируется только
структура (ссылки на файлы, сгруппированные по папкам), а узлы создаются лишь при
раскрытии ветки (`fetchMore`). Размер папки — сумма содержимого (рекурсивно),
считается при индексации. Рекурсивная фильтрация (папка видна, если внутри есть
совпадение) и сортировка — внутри модели.

**База данных** (`db.py`, SQLite). После анализа сохраняется снимок папки/бакета.
Хранится только то, что нельзя вывести из пути (`path, размер, даты, is_dir,
ссылка на автора`); имя/родитель/формат/категория восстанавливаются при загрузке,
автор — через справочник (одна строка на владельца). При повторном анализе
**инкрементно** сравниваются размер и дата: неизменённые файлы берутся из базы
(в т.ч. без повторного чтения автора), и если ничего не изменилось — уже
построенное дерево переиспользуется. «Сжать базу» (VACUUM) возвращает свободное
место ОС.

**Расписание** запускает то же приложение в **безоконном CLI-режиме**
(`--scan` / `--s3-scan` / `--apply-rule`), поэтому логика анализа/правил общая для
интерактивного и фонового запуска.

## Платформы

| Возможность | Windows | macOS / Linux |
|---|---|---|
| Анализ, список/дерево, фильтры, сводка, дубли, правила, S3, база | ✅ | ✅ |
| «Автор» файла | System.Author / владелец (Security API) | имя владельца (по uid) |
| SMB с логином | встроено (WNet API, буква диска) | macOS: встроено (NetFS, `/Volumes`, Связка ключей); Linux: смонтируйте средствами ОС |
| Расписание | Планировщик заданий (+ «как служба SYSTEM») | macOS: `launchd` (агент в `~/Library/LaunchAgents`); Linux: `cron` |
| Дата «Создан» | дата создания | macOS: настоящая дата создания (`st_birthtime`); Linux: ctime |
| Интеграция | Проводник | Finder: «Показать в Finder», Quick Look, иконки файлов, меню macOS |

Горячие клавиши на macOS — с ⌘, на Windows/Linux — с Ctrl (⌘O → Ctrl+O и т.д.).
Все команды есть в строке меню («Файл», «Правка», «Вид», «Объект», «Инструменты»);
«Настройки…» — ⌘, (в меню программы).

**Доступ к папкам на macOS.** При первом анализе «Рабочего стола», «Документов»,
«Загрузок», внешних и сетевых дисков macOS спросит разрешение — ответьте «Разрешить».
Для анализа всего диска (`Macintosh HD`, `~/Library`) дайте приложению «Полный
доступ к диску»: Системные настройки → Конфиденциальность и безопасность →
Полный доступ к диску. Задания расписания используют те же разрешения.

Пути данных зависят от ОС: Windows — `%LOCALAPPDATA%\FolderAnalyzer`, macOS —
`~/Library/Application Support/FolderAnalyzer`, Linux — `~/.local/share/FolderAnalyzer`.

## Сборка портативной версии

PyInstaller собирает **только под текущую ОС** (не кросс-компилирует), поэтому
собирайте на нужной системе. Результат — один файл без установки.

**Windows** (запускать на Windows с Python 3.10+):
```bat
build_windows.bat
REM результат: dist\FolderAnalyzer.exe
```
Скрипт создаёт `.venv`, ставит зависимости и PyInstaller и собирает по
`FolderAnalyzer.spec`. Вручную:
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --clean FolderAnalyzer.spec
```
Пересборка с нуля — команда в разделе истории; иконка (`app_icon.ico`) встроена.

**Linux (Ubuntu и др.)**:
```bash
bash build_linux.sh      # -> dist/FolderAnalyzer (портативный бинарник)
```

**macOS** (запускать на Mac; нужен Python 3.10+ или `uv` — скрипт сам создаст `.venv`):
```bash
./build_macos.sh
# -> dist/FolderAnalyzer.app       — приложение
# -> dist/FolderAnalyzer-2.0.dmg   — установочный образ (перетащить в «Программы»)
```
Спецификация — `FolderAnalyzer-macOS.spec` (onedir-бандл, `Info.plist` с
русскими текстами запросов доступа, поддержка тёмной темы, minimum macOS 12).
Сборка — под архитектуру текущего Python (arm64 на Apple Silicon); для Intel-Mac
соберите на Intel или задайте `TARGET_ARCH=universal2` с universal-Python.
Приложение подписано ad-hoc: при первом запуске скачанной копии — ПКМ →
«Открыть» (или `xattr -dr com.apple.quarantine /Applications/FolderAnalyzer.app`).
Для распространения подпишите сертификатом: `CODESIGN_IDENTITY="Developer ID
Application: …" ./build_macos.sh` и нотаризуйте (`xcrun notarytool`).

Иконку можно перегенерировать: `python make_icon.py` (создаёт
`app_icon.ico/.png`), `python make_icon.py --macos` — `app_icon.icns` по сетке
macOS (вызывается из `build_macos.sh`).

## CLI и автоматизация

Те же операции доступны без окна (используются заданиями расписания):

```bash
# инкрементный анализ папки в базу (+ уведомление при превышении размера)
FolderAnalyzer --scan "\\server\share\folder" --authors --notify-size 107374182400
# на macOS — бинарник внутри бандла:
/Applications/FolderAnalyzer.app/Contents/MacOS/FolderAnalyzer --scan ~/Documents

# анализ бакета S3 (профиль берётся из settings.json)
FolderAnalyzer --s3-scan --notify-size 1099511627776

# применить сохранённое правило (авто-архивация/удаление старых)
FolderAnalyzer --apply-rule "имя_правила"
```
Флаги скана: `--no-recursive`, `--no-dirs`, `--authors`, `--db <путь>`, `--full`
(полный, не инкрементный), `--settings-file <путь>`.

## Где хранятся данные

В каталоге данных приложения (`%LOCALAPPDATA%\FolderAnalyzer` и аналоги):
- `analyzer.db` — база снимков (папку можно сменить в «Настройки…»);
- `settings.json` — путь к базе, профиль S3, данные Telegram;
- `rules.json` — сохранённые правила;
- `logs/` — логи запусков правил и (macOS) всех заданий launchd;
- `tasks/` — launcher-скрипты заданий (Windows).

На macOS задания расписания — файлы `~/Library/LaunchAgents/com.folderanalyzer.job.*.plist`;
настройки окна — `~/Library/Preferences/com.folderanalyzer.FolderAnalyzer.plist`.

## Файлы проекта

| Файл | Назначение |
|------|-----------|
| `app.py` | Главное окно (меню, панель инструментов, виды), диалоги, CLI-режимы |
| `ui_widgets.py` | Боковая панель источников, сводка с категориями, иконки, Finder/Quick Look |
| `model.py` | Модели списка и ленивого дерева, фильтры, категории, ячейки |
| `scanner.py` | Обход файловой системы (фон + headless), метаданные, инкремент, параллельное чтение автора |
| `s3client.py` | Работа с S3 через boto3 (листинг, удаление, перенос, скачивание) |
